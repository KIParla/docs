= KIParla Documentation

KIParla is a corpus of spoken Italian built from recordings collected in university settings across Italy.
This site documents the corpus modules, derived projects, and maintainer guides.

== Corpus modules

The KIParla corpus is split into seven modules, each maintained as an independent repository.

[cols="1,3", options="header"]
|===
| Module | Description

| xref:KIP::index.adoc[KIP]
| Spoken Italian collected at the Universities of Bologna and Turin (2016–2019). ~70 hours, 121 conversations, 184 speakers.

| xref:KIPasti::index.adoc[KIPasti]
| KIP sub-corpus recorded all over Italy.

| xref:ParlaBO::index.adoc[ParlaBO]
| Spoken Italian collected in Bologna.

| xref:ParlaTO::index.adoc[ParlaTO]
| Spoken Italian collected in Turin.

| xref:ParlaBZ::index.adoc[ParlaBZ]
| Spoken Italian collected in South Tyrol (2020–2022). ~5 hours, 10 conversations, 15 speakers.

| xref:Stra-ParlaBO::index.adoc[Stra-ParlaBO]
| Conversations and interviews collected in Bologna and its province with speakers of Italian as a foreign or second language.

| xref:Stra-ParlaTO::index.adoc[Stra-ParlaTO]
| Conversations and interviews collected in Turin and its province with speakers of Italian as a foreign or second language.
|===

All modules share the same file format and metadata schema.
See any module's documentation for a full description of the data structure.

== Transcription conventions

All modules transcribe using the same xref:transcription-conventions.adoc[KIParla
transcription conventions] (enriched notation adapted for spoken Italian).
Where a module adds a symbol or narrows a rule, it is documented on that
module's own *Transcription conventions* page.

The xref:collection::index.adoc[KIParla-collection] aggregates all seven modules into a single downloadable release.
